# DESRU-Enhanced

[English](README.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Русский](README.ru.md)

Неофициальная Windows-утилита для DOOM Eternal на основе [DESRU 1.6.17 от bowsr](https://github.com/bowsr/DESRU). Исходная история Git и авторство сохранены.

## Установка

1. Откройте [Releases](https://github.com/IlyaTsyganov/DESRU-Enhanced/releases/latest) и скачайте **DESRU-Enhanced-v1.1.1-standalone-win-x64.zip** из Assets. Архивы «Source code» предназначены для разработчиков.
2. В Windows 10/11 x64 закройте другие копии DESRU и распакуйте архив целиком в папку с правом записи, сохранив вложенные папки. Перед заменой файлов сделайте резервную копию прежней установки и настроек.
3. Запустите **DESRU.exe**, подтвердите запрос администратора и при необходимости выберите папку игры.
4. Оставьте DESRU работающим и запустите DOOM Eternal обычным способом. Порядок запуска произвольный; отдельный посредник для запуска игры не нужен.

Standalone-архив содержит .NET Desktop Runtime 6.0.36, зависимости, шрифты, freescroll-макрос, meath00k и нативный модуль визуальных дополнений. Предварительная установка DESRU или отдельного .NET не требуется. Исполняемых файлов игры и уровней в архиве нет. Автообновление из оригинального DESRU по умолчанию отключено, чтобы оно не заменило этот форк. Последующие версии устанавливайте из релизов этого репозитория вручную.

## Что добавлено относительно оригинального DESRU

- Защита модбота: удержанное при открытии E/Q больше не переключает вкладку оружия. Внутренний лимит FPS сохраняется, новые нажатия работают после отпускания. Предупреждение появляется только при невозможности подключить защиту. [Подробнее](docs/MODBOT-INPUT.md).
- Спидометры в штатном HUD игры, включая эксклюзивный полный экран: текущая горизонтальная скорость и скорость последнего приземления с кратким импульсом. Раздельные координаты и цвета, общий размер, отдельное включение показателя приземления.
- Настройка прозрачности двух обнаруженных слоёв окрашивания при низком здоровье без изменения здоровья и брони.
- Включение и выключение читов и meath00k во время игры. Выключение возвращает отслеживаемые cvar к значениям до чит-сессии и снимает управляемые читы игрока. Устаревшее требование перезапуска убрано, когда читы и meath00k отключены.
- Показ изменённых защищённых cvar и активных noclip, notarget и god под основными индикаторами. Поддержан любой порядок запуска; скрытие имени драйвера учитывает строки AMD.
- Исправлено повторное включение firewall rule и индикатора F с проверкой реального состояния правила.
- Lighting Fix: сохраняемая галка в Options, статус в Info Panel и буква X. Переключается на ходу и применяется при прямом запуске игры.
- Collision Viewer через консоль: триггеры голубые, блокирующие игрока коллизии уровня зелёные, появляющиеся/исчезающие невидимые стены оранжевые. Отдельной галки и индикатора V нет; команды доступны при включённых читах.
- Объекты рисуются целиком при частичном попадании их границ в радиус. Снят прежний фиксированный лимит геометрии. Фоновая оптимизация удаляет поглощённые и внутренние поверхности, сохраняя видимые линии пересечения, в том числе без заливки. Известные формы без коллизии с игроком отфильтрованы.
- Компактное расположение Options/Trainer, обновлённая справка On-Screen Display и Info Panel, раздел Other со всеми командами DESRU, прокруткой колесом и тёмной полосой в стиле программы.

Сохранены исходные макрос, горячие клавиши, масштабирование, trainer и остальные функции DESRU. Перед спидраном проверяйте правила категории: наличие форка не означает его одобрения для таблиц рекордов.

## Консольные команды

Любая команда без аргументов выводит текущее значение и подсказку.

| Collision Viewer | Действие |
| --- | --- |
| `desru_volumes_show 0/1` | Скрыть/показать все объёмы; в начале каждой игровой сессии 0. |
| `desru_volumes_fill 0/1` | Только контуры / контуры с заливкой; по умолчанию 1. |
| `desru_triggers_show 0/1` | Скрыть/показать триггеры. |
| `desru_collision_show 0/1` | Скрыть/показать коллизии уровня. |
| `desru_invisible_walls_show 0/1` | Скрыть/показать появляющиеся/исчезающие невидимые стены. |
| `desru_volumes_render_distance <метры>` | Радиус отрисовки; по умолчанию 40, например 73.5; конечное неотрицательное число. |

Включите читы, затем введите `desru_volumes_show 1`. Выключение читов скрывает viewer и блокирует его команды. Заливка, видимость категорий и дистанция сохраняются. Линии пересечения появляются с оптимизированной сценой после фонового расчёта.

| Спидометры / окрашивание | Действие |
| --- | --- |
| `desru_speedometer_show 0/1` | Скрыть/показать основной дисплей. |
| `desru_speedometer_showlanding 0/1` | Показатель приземления; основной дисплей также должен быть включён. |
| `desru_speedometer_x_pos <пиксели> [current\|landing]` | Координата от левого края. |
| `desru_speedometer_y_pos <пиксели> [current\|landing]` | Координата от верхнего края. |
| `desru_speedometer_size <0.1–10>` | Размер текста обоих показателей. |
| `desru_speedometer_color <R> <G> <B> [current\|landing]` | Цвет RGB, каждый канал 0–255. |
| `desru_lowhptintopacity <0–100>` | Непрозрачность окрашивания при низком здоровье; по умолчанию 100. |

Эти команды не требуют читов. Скорость показывается в метрах в секунду с двумя знаками; `--` означает, что приземления ещё не было. Координаты задаются в физических пикселях экрана от верхнего левого угла. Без current/landing координаты или цвет меняются для обоих показателей. Примеры: `desru_speedometer_x_pos 100 landing`, `desru_speedometer_color 255 255 255 current`. Настройки сохраняются во время работы DESRU. Начальные значения: оба показателя включены и белые, current (0, 480), landing (100, 480), размер 3.5; существующие настройки имеют приоритет.

## Совместимость и сборка

Искусственного ограничения Collision Viewer по версии игры нет; поиск структур движка всё равно должен завершиться успешно. HUD/окрашивание проверялись на 1.1 и Steam 6.66 Rev 3.2, viewer/lighting — на 1.0 Release. Все сочетания функций, сборок и драйверов не проверены. На отдельных поверхностях возможно остаточное мерцание; большая дальность увеличивает нагрузку.

Сборка в Windows: Visual Studio MSBuild, .NET Desktop SDK и инструменты C++ (CMake, Ninja, Windows SDK). Заголовки Vulkan включены. Для COM-библиотеки firewall нужен MSBuild из Visual Studio. Параметр `/p:SkipBundleBuildEvents=true` отключает старые события замены выходной папки. Команды и подготовка ресурсов: [standalone-сборка](docs/STANDALONE.md), [английский README](README.md). Подробнее: [спидометры](docs/SPEEDOMETERS.md), [визуальные функции](docs/VISUAL-FEATURES.md), [читы](docs/LIVE-CHEATS.md), [firewall](docs/FIREWALL.md), [исходный README](docs/UPSTREAM-README.md).
